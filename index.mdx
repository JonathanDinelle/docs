Veval wraps your agent runs and LLM calls to record traces: inputs, outputs, step timing, token counts, and cost. You run scenarios and assertions against those traces in CI to catch regressions before they reach production.

## Why use Veval

* **Every step, recorded.** Each agent run becomes a trace with its steps, inputs, outputs, timing, tokens, and cost.
* **Tests without LLM calls.** Replay a recorded production trace with mocked LLM responses. Deterministic, fast, and free.
* **Strict by default.** If your agent makes a call the recording doesn't have, replay throws instead of calling the live LLM.
* **Regressions you can read.** Snapshots compare a run against a known-good baseline and report changed prompts, tool arguments, and added, removed, or moved steps, with a line diff.
* **Built-in checks.** Assert on errors, step count, cost, duration, outputs, and tool calls, or grade outputs with an LLM judge.
* **Three SDKs, one model.** C#, Python, and Node share the same concepts and method names.
